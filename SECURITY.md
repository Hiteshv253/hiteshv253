# Security Policy

## Supported Versions

Only the latest release versions receive security patches and updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x |  Yes |
| < 1.0.0 |  No |

## Reporting a Vulnerability

We take the security of our deployment environments, templates, and code seriously. If you discover a vulnerability, please do not disclose it publicly.

1. **Email Reports**: Send detailed vulnerability reports to [hiteshv253@gmail.com](mailto:hiteshv253@gmail.com).
2. **Details to Include**:
   - Description of the threat vector.
   - Proof of Concept (PoC) steps or script to replicate.
   - Potential impact on container security, cloud access policies, or database isolation.
3. **Response Timeline**: We will acknowledge reports within 48 hours and coordinate patches within 14 days of confirmation.
